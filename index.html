Watkins Bros Mobile Detailing

Design System Specimen

A reusable design system for a mobile auto detailing service in the DMV area.

S1 — Foundation and Reset

This design system uses a selective CSS reset to preserve useful browser defaults.

Reset Decisions

  • Use border-box sizing to make layouts easier to control.
  • Preserve visible keyboard focus indicators for accessibility.
  • Keep meaningful heading and list styles instead of removing every browser default.

S3 — Typography

Watkins Bros Type System

Clear, Readable Typography

Good typography helps customers understand our mobile detailing services, pricing, and appointment information.

Supporting Heading

Our design system uses readable fonts, comfortable line spacing, and responsive heading sizes across different screen widths.

Typography Guidelines

  • Use Arial for body text and controls.
  • Use Georgia for headings and titles.
  • Keep paragraphs at a readable line length.
  • Maintain clear spacing between sections.

Metadata example: Updated October 2026

CSS example: font-family: var(--font-body);

Review typography tokens

Font Source and Fallback Plan

Body font: Arial, with Segoe UI and sans-serif fallbacks.

Display font: Georgia, with Times New Roman and serif fallbacks.

These are system-installed fonts. No external font files are downloaded or redistributed. Available weights and styles depend on the operating system and installed fonts.
